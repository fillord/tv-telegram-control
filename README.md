# Управление Android TV через Telegram

Бот управляет одним или несколькими телевизорами через сетевой ADB. В Telegram можно включать телевизоры, переводить их в ожидание, открывать сайт, управлять громкостью и D-pad, перезагружать устройства и получать скриншоты. Рекомендуемый вариант запуска — Docker на постоянно включённом Linux-сервере в локальной сети телевизоров.

Поддерживаются телевизоры и приставки на Android TV, Google TV и Fire TV с доступным сетевым ADB. Samsung Tizen, LG webOS и Roku требуют другой интеграции.

## Возможности

- отдельное управление каждым телевизором и одновременные команды для всех;
- доступ только для Telegram ID из белого списка;
- автоматическое восстановление зависшего ADB-сервера;
- контроль доступности телевизоров и сайта;
- защита от автоматического сна с уважением к ручной кнопке «Ожидание»;
- Wake-on-LAN при наличии поддержки со стороны телевизора;
- Docker-развёртывание с автозапуском и сохранением ADB-ключей.

## Быстрый запуск на Linux-сервере через Docker

### 1. Требования

- Linux-сервер с Docker и Docker Compose;
- сервер и телевизоры находятся в одной локальной сети или имеют прямой маршрут;
- каждому телевизору назначен постоянный IP;
- на телевизорах включён сетевой ADB, обычно на порту `5555`;
- отдельный Telegram-бот, созданный через **@BotFather**.

Проверьте доступность телевизора с сервера:

```bash
ping -c 3 192.168.0.108
python3 -c "import socket; socket.create_connection(('192.168.0.108', 5555), 3); print('ADB port is reachable')"
```

### 2. Установка проекта

```bash
mkdir -p /home/$USER/docker
cd /home/$USER/docker
git clone https://github.com/fillord/tv-telegram-control.git
cd tv-telegram-control
mkdir -p data logs adb
chmod 700 data adb
cp config.example.json data/config.json
chmod 600 data/config.json
```

### 3. Конфигурация

Отредактируйте `data/config.json`:

```json
{
  "telegram_token": "TOKEN_FROM_BOTFATHER",
  "allowed_user_ids": [123456789],
  "adb_path": "/usr/bin/adb",
  "refresh_interval_seconds": 60,
  "healthcheck_interval_seconds": 60,
  "healthcheck_failure_threshold": 3,
  "healthcheck_recovery_threshold": 2,
  "auto_refresh": true,
  "keep_awake": true,
  "keep_awake_interval_seconds": 60,
  "tvs": [
    {
      "name": "Телевизор в зале",
      "ip": "192.168.0.108",
      "port": 5555,
      "url": "https://example.org/tv",
      "mac": "AA:BB:CC:DD:EE:FF"
    }
  ]
}
```

Если Telegram ID неизвестен, запустите бота с временным числом в `allowed_user_ids`, отправьте боту `/id`, затем внесите полученный ID в конфигурацию.

В `compose.yaml` контейнер запускается как пользователь `1000:1000`. Если `id -u` или `id -g` возвращает другое значение, измените поле `user` в `compose.yaml`.

### 4. Запуск

```bash
docker compose up -d --build
docker compose ps
docker compose logs -f --tail=100
```

При первом подключении выполните:

```bash
docker exec tv-telegram-control adb devices -l
```

Если устройство имеет статус `unauthorized`, подтвердите RSA-запрос на экране телевизора и включите «Всегда разрешать». ADB-ключ хранится в каталоге `adb/` и не теряется при пересоздании контейнера.

### 5. Проверка

1. Отправьте боту `/start` в личном чате.
2. Проверьте кнопки громкости и «Домой».
3. Проверьте «Открыть сайт».
4. Нажмите «Ожидание»: телевизор должен уснуть и не просыпаться от фонового контроля.
5. Нажмите «Включить»: ручной сон отменяется, защита от случайного сна активируется снова.

### 6. Обновление и обслуживание

```bash
git pull
docker compose up -d --build
docker compose logs --tail=100
```

Остановка и запуск:

```bash
docker compose stop
docker compose start
```

Резервное копирование должно включать `data/config.json` и каталог `adb/`. Файл `adb/adbkey` является закрытым ключом и не должен публиковаться.

## Подготовка телевизоров

1. На каждом ТВ включите «Быстрый старт» и «Режим ожидания сети».
2. В параметрах разработчика включите отладку и один раз разрешите доступ этому Mac. Проверьте соединение для каждого IP: `~/Downloads/platform-tools/adb connect 192.168.0.108:5555`, затем `~/Downloads/platform-tools/adb devices`. Рядом с адресом должно быть `device`.
3. Установите ТВ-браузер. До настройки бота проверьте, что команда открывает страницу именно в браузере:
   `~/Downloads/platform-tools/adb -s 192.168.0.108:5555 shell am start -a android.intent.action.VIEW -d 'https://example.org/tv'`
   Если ТВ пишет «Действие не поддерживается», браузер не принимает внешние ссылки. Кнопка «Открыть сайт» в боте тоже не сможет открыть их через этот браузер. Проверьте другой ТВ-браузер, прежде чем включать автоматическое открытие.
4. Назначьте каждому ТВ постоянный IP в настройках DHCP вашего роутера. После смены IP обновите `config.json`.

## Telegram и Mac

1. В Telegram откройте официального **@BotFather**, отправьте `/newbot`, создайте бота и скопируйте выданный токен. Никому его не передавайте.
2. Распакуйте архив, откройте Терминал и перейдите в каталог `tv-telegram-control` (можно набрать `cd ` и перетащить папку в окно Терминала). Проверьте `python3 --version`.
3. Выполните `cp config.example.json config.json`. Откройте `config.json` в TextEdit как обычный текст. Вставьте токен в `telegram_token`, проверьте `adb_path`, пропишите реальные IP и названия ТВ; удалите второй пример, если второго ТВ пока нет. Сохраните файл, затем выполните `chmod 600 config.json`.
4. Запустите `python3 tv_bot.py`. В личном чате с ботом отправьте `/id`. Бот ответит числом — вашим Telegram ID. Остановите программу клавишами `Ctrl+C`, вставьте число в `allowed_user_ids`, например `"allowed_user_ids": [123456789]`, сохраните и вновь запустите `python3 tv_bot.py`.
5. В личном чате с ботом отправьте `/start` и нажимайте кнопки. Бот обрабатывает только личные сообщения от ID, перечисленных в `allowed_user_ids`.

Чтобы бот работал постоянно, Mac должен быть включён и иметь доступ к сети. Для первого испытания оставьте открытым окно Терминала.

## Автозапуск в фоне на macOS (`launchd`)

Для круглосуточной фоновой работы без открытого окна Терминала используйте готовый скрипт управления:

- **Установить и запустить:** `./service.sh install` (служба запускается с `caffeinate -i`, предотвращая автоматический сон Mac; закрытие крышки ноутбука по-прежнему может остановить работу).
- **Проверить статус:** `./service.sh status`
- **Смотреть логи онлайн:** `./service.sh logs` (логи пишутся в `~/Library/Logs/tv_bot.log`, автоматически ротируются по 2 МБ и хранят три архива)
- **Остановить:** `./service.sh stop`
- **Удалить из автозапуска:** `./service.sh uninstall`

## Как работают команды и статусы

- **Добавление нового ТВ:** прямо в Telegram нажмите кнопку «➕ Добавить ТВ» в главном меню или отправьте команду `/addtv`.
  - Пошаговый режим: бот запросит IP-адрес (например `192.168.0.120` или с нестандартным портом `192.168.0.120:5555`), затем имя ТВ, а также предложит использовать ссылку по умолчанию одной кнопкой.
  - Быстрая команда в одну строку: `/addtv 192.168.0.120 TCL Зал`. Необязательную ссылку можно указать последним аргументом: `/addtv 192.168.0.120 TCL Зал https://example.com/tv`.
  - Телевизор сразу сохраняется в `config.json` и появляется в меню без перезапуска бота.
- **Удаление ТВ:** в меню действий нужного телевизора доступна кнопка «🗑 Удалить этот ТВ» с запросом подтверждения.
- **Динамический статус ТВ в меню:** при открытии меню и по кнопке «🔄 Обновить статусы» бот опрашивает телевизоры параллельно и показывает текущее состояние:
  - `🟢 (Включен)` — ТВ включен, экран активен.
  - `💤 (Сон)` — ТВ подключен к сети и находится в режиме ожидания (standby).
  - `🔴 (Оффлайн)` — ТВ выключен из розетки или отключен от локальной сети.
  - `🟡 (Не авторизован)` — требуется подтвердить отладку по ADB на экране телевизора.
  - `⚪ (Состояние неизвестно)` — ADB доступен, но состояние экрана надёжно определить не удалось; автообновление для такого ТВ не выполняется.
- **Умное автообновление (Smart Refresh):** фоновое обновление сайта отправляет команду только бодрствующим телевизорам (`🟢`), исключая случайное включение спящих ТВ ночью.
- **Ожидание:** ADB отправляет `KEYCODE_SLEEP` (223).
- **Включить:** ADB отправляет `KEYCODE_WAKEUP` (224). Если ADB-соединение исчезает в ожидании, опционально укажите в настройках ТВ `"mac": "AA:BB:CC:DD:EE:FF"`: бот сначала пошлёт Wake-on-LAN. Его поддержка конкретным ТВ должна быть проверена отдельно; включённый сетевой режим сам по себе не гарантирует Wake-on-LAN.
- **Открыть сайт:** Android получает команду `ACTION_VIEW` с адресом из настроек. Должно быть приложение, принимающее такие ссылки. Бот сообщает об отправке команды, а фактическое отображение страницы нужно проверить на экране.
- **Включить + сайт:** отправляет пробуждение, ждёт три секунды, открывает страницу. После полного выключения ТВ (например, выниманием вилки) дистанционное пробуждение недоступно.
- **Скриншот экрана:** ADB выполняет `screencap -p` для захвата текущего кадра на экране телевизора и отправляет полученный PNG в Telegram-чат. Доступно по кнопке «📸 Скриншот» в меню ТВ или по команде `/screenshot` (также `/screenshot 1`, `/screenshot all`, `/shot`).
- **Управление громкостью:** отправляет через `adb shell input keyevent` коды `KEYCODE_VOLUME_DOWN` (25), `KEYCODE_VOLUME_UP` (24) и `KEYCODE_VOLUME_MUTE` (164). Доступно кнопками «🔉 Тише», «🔇 Mute», «🔊 Громче» в меню действий ТВ или командами `/voldown`, `/volup`, `/mute`.
- **Стрелки навигации (D-pad):** отправляет через `adb shell input keyevent` коды `KEYCODE_DPAD_UP` (19), `KEYCODE_DPAD_DOWN` (20), `KEYCODE_DPAD_LEFT` (21), `KEYCODE_DPAD_RIGHT` (22), выбор `KEYCODE_DPAD_CENTER` (23), «Назад» (4) и «Домой» (3). Доступно в меню действий каждого ТВ. Нажатия на кнопки пульта подтверждаются мгновенным всплывающим уведомлением в Telegram без спама новыми сообщениями в чате.

Новых пользователей добавляйте вручную по их Telegram ID в `allowed_user_ids`. Не добавляйте бота в группы. Не передавайте файл `config.json` с токеном другим людям.

ADB-порт телевизора должен быть доступен только из доверенной локальной сети. Не пробрасывайте порт `5555` в Интернет. Скриншоты отправляются через Telegram, поэтому не используйте эту функцию для экранов с конфиденциальными данными.

Проверка сайта выполняется раз в `healthcheck_interval_seconds` (по умолчанию 60 секунд). Уведомление об отключении отправляется после `healthcheck_failure_threshold` последовательных ошибок, а восстановление — после `healthcheck_recovery_threshold` успешных проверок. Это защищает от уведомлений из-за одиночных сетевых сбоев.
