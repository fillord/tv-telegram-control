# Управление Android TV через Telegram

Бот управляет одним или несколькими телевизорами через сетевой ADB. В Telegram можно включать телевизоры, переводить их в ожидание, открывать сайт, управлять громкостью и D-pad, перезагружать устройства и получать скриншоты. Рекомендуемый вариант запуска — Docker на постоянно включённом Linux-сервере в локальной сети телевизоров.

Поддерживаются телевизоры и приставки на Android TV, Google TV и Fire TV с доступным сетевым ADB. Samsung Tizen, LG webOS и Roku требуют другой интеграции.

Для подключения нового предприятия используйте
[пакет проверки совместимости и коммерческого внедрения](docs/README.md). Он
включает анкету клиента, подготовку ADB, протокол испытаний, реестр моделей и
шаблон технического заключения.

Пошаговая подготовка отдельной установки находится в
[инструкции для сервера заказчика](docs/deployment/customer-server.md).

## Возможности

- отдельное управление каждым телевизором и одновременные команды для всех;
- доступ только для Telegram ID из белого списка;
- автоматическое восстановление зависшего ADB-сервера;
- контроль доступности телевизоров и сайта;
- защита от автоматического сна с уважением к ручной кнопке «Ожидание»;
- расписание включения и ожидания для каждого ТВ с автоматическим открытием сайта;
- Wake-on-LAN при наличии поддержки со стороны телевизора;
- Docker-развёртывание с автозапуском и сохранением ADB-ключей;
- фоновый кэш статусов: меню открывается без ожидания последовательных ADB-проверок;
- группы телевизоров, редактирование имени/IP/порта/MAC и порядка прямо в Telegram;
- экран диагностики, переподключение ADB и журнал последних событий;
- раздельное хранение конфигурации, рабочего состояния и секрета Telegram.

Интерфейс Telegram построен как компактная панель: главное меню показывает
сводку состояний, а пульт, звук, расписание, настройки и техническая информация
открываются на отдельных экранах. Переходы редактируют одно сообщение и не
засоряют чат новыми меню.

## Быстрый запуск на Linux-сервере через Docker

### 1. Требования

- Linux-сервер с Docker и Docker Compose;
- сервер и телевизоры находятся в одной локальной сети или имеют прямой маршрут;
- каждому телевизору назначен постоянный IP;
- на телевизорах включён сетевой ADB, обычно на порту `5555`;
- отдельный Telegram-бот, созданный через **@BotFather**.

Проверьте доступность телевизора с сервера:

```bash
ping -c 3 192.168.0.108
python3 -c "import socket; socket.create_connection(('192.168.0.108', 5555), 3); print('ADB port is reachable')"
```

### 2. Установка проекта

```bash
mkdir -p /home/$USER/docker
cd /home/$USER/docker
git clone <REPOSITORY_URL> tv-telegram-control
cd tv-telegram-control
mkdir -p data logs adb secrets
chmod 700 data adb secrets
cp config.example.json data/config.json
cp .env.example .env
printf '%s\n' 'TOKEN_FROM_BOTFATHER' > secrets/telegram_token
chmod 600 data/config.json
chmod 600 secrets/telegram_token
chmod 600 .env
```

### 3. Конфигурация

Отредактируйте `data/config.json`:

```json
{
  "allowed_user_ids": [123456789],
  "adb_path": "/usr/bin/adb",
  "refresh_interval_seconds": 60,
  "healthcheck_interval_seconds": 60,
  "healthcheck_failure_threshold": 3,
  "healthcheck_recovery_threshold": 2,
  "auto_refresh": false,
  "keep_awake": true,
  "keep_awake_interval_seconds": 60,
  "wake_timeout_seconds": 45,
  "wake_verify_timeout_seconds": 10,
  "schedule_retry_attempts": 3,
  "schedule_retry_delay_seconds": 60,
  "log_repeat_interval_seconds": 900,
  "status_cache_seconds": 15,
  "status_poll_interval_seconds": 10,
  "history_max_events": 1000,
  "timezone": "Asia/Almaty",
  "tvs": [
    {
      "name": "Телевизор в зале",
      "ip": "192.168.0.108",
      "port": 5555,
      "url": "https://example.org/tv",
      "mac": "AA:BB:CC:DD:EE:FF",
      "auto_refresh": true,
      "group": "Первый этаж",
      "schedule": {
        "enabled": true,
        "on": "09:00",
        "off": "22:00",
        "days": [0, 1, 2, 3, 4, 5, 6]
      }
    }
  ]
}
```

Если Telegram ID неизвестен, запустите бота с временным числом в `allowed_user_ids`, отправьте боту `/id`, затем внесите полученный ID в конфигурацию.

В `.env` укажите результат `id -u`, `id -g` и часовой пояс сервера в
переменных `TV_BOT_UID`, `TV_BOT_GID` и `TV_BOT_TIMEZONE`. Для новой установки
можно вместо ручного копирования использовать `scripts/init_installation.py` —
он создаст конфигурацию и запросит токен скрыто.

### 4. Запуск

```bash
docker compose up -d --build
docker compose ps
docker compose logs -f --tail=100
```

Перед запуском можно проверить рабочую конфигурацию без вывода токена и Telegram ID:

```bash
docker compose run --rm tv-telegram-control python3 /app/tv_bot.py --check-config
```

После успешного запуска `docker compose ps` должен показывать состояние `healthy`.

При первом подключении выполните:

```bash
docker exec tv-telegram-control adb devices -l
```

Если устройство имеет статус `unauthorized`, подтвердите RSA-запрос на экране телевизора и включите «Всегда разрешать». ADB-ключ хранится в каталоге `adb/` и не теряется при пересоздании контейнера.

### 5. Проверка

1. Отправьте боту `/start` в личном чате.
2. Проверьте кнопки громкости и «Домой».
3. Проверьте «Открыть сайт».
4. Нажмите «Ожидание»: телевизор должен уснуть и не просыпаться от фонового контроля.
5. Нажмите «Включить»: ручной сон отменяется, защита от случайного сна активируется снова.

### 6. Обновление и обслуживание

```bash
git pull
docker compose up -d --build
docker compose logs --tail=100
```

Остановка и запуск:

```bash
docker compose stop
docker compose start
```

Резервное копирование должно включать каталоги `data/`, `secrets`, `adb/` и файл
`.env`. Файлы `secrets/telegram_token` и `adb/adbkey` являются закрытыми ключами
и не должны публиковаться. `scripts/backup.sh` создаёт защищённую копию, а
`scripts/deploy.sh` автоматически запускает тесты, сохраняет рабочую версию,
разворачивает обновление, ждёт `healthy` и выполняет откат при ошибке.

## Подготовка телевизоров

1. Включите режим Google TV или Android TV.
2. Включите параметры разработчика и сетевую отладку ADB.
3. Включите «Быстрый запуск» и «Ожидание по сети / Network Standby». Без этих параметров некоторые модели полностью отключают сеть во сне и не принимают Wake-on-LAN.
4. Назначьте каждому телевизору постоянный IP через DHCP reservation на роутере.
5. Запишите MAC-адрес каждого телевизора.
6. После запуска контейнера выполните `docker exec tv-telegram-control adb devices -l` и подтвердите RSA-доступ на экране телевизора.
7. Проверьте открытие сайта из контейнера:

```bash
docker exec tv-telegram-control adb -s 192.168.0.108:5555 shell am start \
  -a android.intent.action.VIEW -d 'https://example.org/tv'
```

Если телевизор сообщает, что действие не поддерживается, установите браузер,
принимающий внешние веб-ссылки. HTTPS используется по умолчанию. Для строго
определённого внутреннего HTTP-адреса добавьте полный URL в
`TV_BOT_HTTP_ALLOWED_URLS` файла `.env` и пересоздайте контейнер.

## Настройка Telegram

1. Откройте официального **@BotFather** и отправьте `/newbot`.
2. Сохраните токен одной строкой в `secrets/telegram_token`; не публикуйте его и не отправляйте посторонним.
3. Запустите контейнер и отправьте боту `/id` в личном чате.
4. Добавьте полученный ID в `allowed_user_ids` и пересоздайте контейнер командой `docker compose up -d`.
5. Отправьте `/start`. Бот принимает команды только в личных чатах от пользователей из белого списка.

## Как работают команды и статусы

- **Добавление нового ТВ:** прямо в Telegram нажмите кнопку «➕ Добавить ТВ» в главном меню или отправьте команду `/addtv`.
  - Пошаговый режим: бот запросит IP-адрес, MAC-адрес, название и веб-ссылку. Незашифрованный HTTP принимается только при точном совпадении с `TV_BOT_HTTP_ALLOWED_URLS`.
  - Быстрая команда с IP и MAC: `/addtv 192.168.0.120 AA:BB:CC:DD:EE:FF TCL Зал https://example.com/tv`.
  - Старый формат без MAC также поддерживается: `/addtv 192.168.0.120 TCL Зал https://example.com/tv`.
  - Телевизор сразу сохраняется в `data/config.json` и появляется в меню без перезапуска бота.
- **Удаление ТВ:** в меню действий нужного телевизора доступна кнопка «🗑 Удалить этот ТВ» с запросом подтверждения.
- **Редактирование и группы:** экран «✏️ Данные ТВ» меняет название, адрес, порт, MAC, группу и порядок без ручного редактирования JSON. Кнопка группы управляет всеми ТВ группы параллельно.
- **Диагностика:** показывает доступность порта, авторизацию ADB, состояние экрана, сайт, возраст кэша и последнее событие; доступны повторная проверка и переподключение ADB.
- **История:** последние команды, сбои, восстановления, проверки и изменения сохраняются в `data/history.jsonl` и доступны из Telegram.
- **Динамический статус ТВ в меню:** фоновый поток обновляет кэш параллельно каждые `status_poll_interval_seconds`; меню использует готовый снимок, а кнопка «🔄 Обновить» принудительно опрашивает устройства:
  - `🟢 (Включен)` — ТВ включен, экран активен.
  - `💤 (Сон)` — ТВ подключен к сети и находится в режиме ожидания (standby).
  - `🔴 (Оффлайн)` — ТВ выключен из розетки или отключен от локальной сети.
  - `🟡 (Не авторизован)` — требуется подтвердить отладку по ADB на экране телевизора.
  - `⚪ (Состояние неизвестно)` — ADB доступен, но состояние экрана надёжно определить не удалось; автообновление для такого ТВ не выполняется.
- **Умное автообновление (Smart Refresh):** фоновое обновление сайта отправляет команду только бодрствующим телевизорам (`🟢`), исключая случайное включение спящих ТВ ночью.
- **Ожидание:** ADB отправляет `KEYCODE_SLEEP` (223).
- **Включить:** ADB отправляет `KEYCODE_WAKEUP` (224). Если ADB-соединение исчезает в ожидании, опционально укажите в настройках ТВ `"mac": "AA:BB:CC:DD:EE:FF"`: бот сначала пошлёт Wake-on-LAN. Его поддержка конкретным ТВ должна быть проверена отдельно; включённый сетевой режим сам по себе не гарантирует Wake-on-LAN.
- **Открыть сайт:** Android получает команду `ACTION_VIEW` с адресом из настроек. Должно быть приложение, принимающее такие ссылки. Бот сообщает об отправке команды, а фактическое отображение страницы нужно проверить на экране. Если Android показывает выбор приложений, укажите в настройках телевизора `"browser_package": "com.yandex.browser.tv"` с фактическим именем пакета установленного браузера.
- **Включить + сайт:** отправляет пробуждение, ждёт три секунды, открывает страницу. После полного выключения ТВ (например, выниманием вилки) дистанционное пробуждение недоступно.
- **Расписание:** нажмите «🕒 Расписание» в главном меню или в меню нужного ТВ. Можно настроить один телевизор либо сразу все. Отправьте время включения, время перехода в ожидание и дни одним сообщением: `09:00 22:00 каждый день`, `08:30 18:00 будни` или `10:00 20:00 пн,ср,пт`. В момент включения бот выполняет «Включить + сайт», поэтому автоматически открывает ссылку, сохранённую для этого телевизора. Часовой пояс задаётся параметром `timezone` (по умолчанию `Asia/Almaty`). Бот восстанавливает последнее пропущенное состояние после перезапуска, не отмечает неудачную команду выполненной и повторяет её до `schedule_retry_attempts` раз с интервалом `schedule_retry_delay_seconds`.
- **Скриншот экрана:** ADB выполняет `screencap -p` для захвата текущего кадра на экране телевизора и отправляет полученный PNG в Telegram-чат. Доступно по кнопке «📸 Скриншот» в меню ТВ или по команде `/screenshot` (также `/screenshot 1`, `/screenshot all`, `/shot`).
- **Управление громкостью:** отправляет через `adb shell input keyevent` коды `KEYCODE_VOLUME_DOWN` (25), `KEYCODE_VOLUME_UP` (24) и `KEYCODE_VOLUME_MUTE` (164). Доступно кнопками «🔉 Тише», «🔇 Mute», «🔊 Громче» в меню действий ТВ или командами `/voldown`, `/volup`, `/mute`.
- **Стрелки навигации (D-pad):** отправляет через `adb shell input keyevent` коды `KEYCODE_DPAD_UP` (19), `KEYCODE_DPAD_DOWN` (20), `KEYCODE_DPAD_LEFT` (21), `KEYCODE_DPAD_RIGHT` (22), выбор `KEYCODE_DPAD_CENTER` (23), «Назад» (4) и «Домой» (3). Доступно в меню действий каждого ТВ. Нажатия на кнопки пульта подтверждаются мгновенным всплывающим уведомлением в Telegram без спама новыми сообщениями в чате.

Постоянные настройки хранятся в `data/config.json`, изменяемое состояние сна и выполнений расписания — в `data/state.json`, история — в `data/history.jsonl`, токен — в `secrets/telegram_token`. Новых пользователей добавляйте вручную по их Telegram ID в `allowed_user_ids`. Не добавляйте бота в группы.

ADB-порт телевизора должен быть доступен только из доверенной локальной сети. Не пробрасывайте порт `5555` в Интернет. Скриншоты отправляются через Telegram, поэтому не используйте эту функцию для экранов с конфиденциальными данными.

Проверка сайта выполняется раз в `healthcheck_interval_seconds` (по умолчанию 60 секунд). Уведомление об отключении отправляется после `healthcheck_failure_threshold` последовательных ошибок, а восстановление — после `healthcheck_recovery_threshold` успешных проверок. Это защищает от уведомлений из-за одиночных сетевых сбоев.

## Проверка после изменений

Запустите автоматические тесты:

`python3 -m unittest discover -s tests -v`

GitHub Actions дополнительно проверяет компиляцию, пример конфигурации и сборку Docker-образа.
