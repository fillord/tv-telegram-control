# Правила проекта TV Telegram Control для Antigravity

## Архитектура и стек
- **Python 3**: Проект опирается исключительно на стандартную библиотеку Python (`urllib`, `socket`, `subprocess`, `threading`, `json`, `concurrent.futures`). Не добавлять сторонние зависимости без явного запроса пользователя.
- **Сетевое взаимодействие**: 
  - Все соединения с ТВ по ADB защищаются предварительной проверкой сокета через `is_device_reachable(ip, port, timeout=1.0)`.
  - При ошибках соединения всегда вызывать `adb disconnect <address>`, чтобы избежать залипания сокетов в ADB Server.
  - Операции над несколькими телевизорами (`target == "all"`) всегда выполнять параллельно через `operate_many()` или `ThreadPoolExecutor`.
  - Главный поток обработки Telegram-апдейтов (`getUpdates`) никогда не блокировать — обработка выносится в `worker_pool`.

## Безопасность
- Никогда не выводить и не логировать в открытом виде токен бота из `config.json`.
- Доступ к командам разрешен только пользователям из `allowed_user_ids`.
- Обрабатывать только приватные чаты (`chat.get("type") == "private"`).
