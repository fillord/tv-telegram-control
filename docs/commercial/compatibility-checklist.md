# Протокол проверки совместимости

Проверка проводится на реальном телевизоре с той же прошивкой, которая будет
использоваться на объекте. Для каждой модели создаётся отдельный отчёт.

## 1. Идентификация

- [ ] Модель и производитель совпадают с анкетой.
- [ ] Записаны версия ОС, прошивки и build fingerprint.
- [ ] Зафиксированы IP, MAC и ADB-порт.
- [ ] Определён режим: TCP 5555 или Wireless debugging/pairing.

## 2. Сеть и авторизация

- [ ] TCP-порт доступен только из управляющей сети.
- [ ] `adb connect` завершается успешно.
- [ ] `adb get-state` возвращает `device`.
- [ ] RSA/pairing сохраняется после повторного подключения.
- [ ] После перезапуска роутера связь восстанавливается.
- [ ] После перезагрузки телевизора авторизация сохраняется.

## 3. Управление

- [ ] Home.
- [ ] Back.
- [ ] D-pad и OK.
- [ ] Громче, тише и mute.
- [ ] Переход в ожидание.
- [ ] Пробуждение из обычного ожидания.
- [ ] Пробуждение после 15 минут ожидания.
- [ ] Перезагрузка телевизора — только по разрешению клиента.

## 4. Состояние питания

- [ ] Состояние «включён» определяется корректно.
- [ ] Состояние «сон» определяется корректно.
- [ ] Отключённое устройство не определяется как включённое.
- [ ] Ручной сон не отменяется фоновым контролем.
- [ ] Зафиксировано поведение ADB-порта в глубоком сне.

## 5. Страница и браузер

- [ ] Веб-ссылка открывается через `ACTION_VIEW`.
- [ ] Выбран корректный браузер по умолчанию.
- [ ] При необходимости зафиксирован пакет браузера в `browser_package`.
- [ ] Нет постоянного диалога выбора приложения.
- [ ] Страница открывается после перезагрузки.
- [ ] Страница открывается после пробуждения.
- [ ] Автообновление не пробуждает спящий экран.
- [ ] Скриншот соответствует изображению на экране.

## 6. Отказоустойчивость

- [ ] Проверено кратковременное отключение сети.
- [ ] После продления DHCP-аренды зарезервированный IP не изменился.
- [ ] Проверен перезапуск контейнера бота.
- [ ] Проверено автоматическое переподключение ADB.
- [ ] Проведена работа минимум 24 часа без потери управления.
- [ ] Для сертификации уровня A проведён тест 72 часа.

## 7. Классификация

- [ ] Уровень A — всё обязательное работает.
- [ ] Уровень B — основное управление работает, ограничения перечислены.
- [ ] Уровень C — только пилотная эксплуатация.
- [ ] Не поддерживается.

Критические причины отказа: ADB нельзя включить, авторизация постоянно
сбрасывается, страница не запускается, соединение не восстанавливается или
устройство требует регулярного физического вмешательства.
