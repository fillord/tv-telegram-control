# Коммерческое подключение телевизоров по ADB

Этот раздел описывает подключение предприятий без внешних HDMI-плееров. Продукт
работает только с телевизорами и приставками, которые успешно проходят проверку
сетевого ADB.

Документы используются в следующем порядке:

1. [Границы продукта и уровни поддержки](commercial/product-scope.md)
2. [Анкета клиента](commercial/client-questionnaire.md)
3. [Инструкция по подготовке ADB](commercial/adb-onboarding.md)
4. [Протокол проверки совместимости](commercial/compatibility-checklist.md)
5. [Реестр протестированных моделей](commercial/compatibility-matrix.md)
6. [Шаблон заключения для клиента](commercial/test-report-template.md)
7. [План первого пилота](commercial/pilot-plan.md)

Главное правило: договорённость о подключении даётся по результату проверки
конкретной модели и версии прошивки, а не только по названию производителя.
